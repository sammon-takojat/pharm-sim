# Measuring cylinder test

User story: Käyttäjänä pystyn löytämään mittalaasin pelitilasta.

Hyväksymiskriteerit: Mittalasi on pelitilassa.

Käynnistin pelin paikallisesti muutoshaarasta, johon oli liitetty viimeisin dev-haara. Löysin mittalasin pelitilan työpöydältä seisomassa. Pelaajana pystyin tarttumaan mittalasiin, liikuttamaan sitä peliympäristössä ja päästämään siitä irti.
