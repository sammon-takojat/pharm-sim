# pH paper test
User story: Käyttäjänä pystyn mittaamaan aineen pH:n pH-paperilla.

Hyväksymiskriteerit: PH-paperin väri muuttuu liuoksen pH-arvon mukaan.

Ominaisuus on testattu manuaalisesti testaamalla pH paperin käyttäytyvän oikein sen koskettaessa erilaisen pH arvon omaavia nesteitä.

Kun pH on 0 niin pH paperin väri on punainen  
Kun pH lähestyy 0->4 niin pH paperin väri lähestyy keltaista  
Kun pH lähestyy 4->7 niin pH paperin väri lähestyy vihreää  
Kun pH lähestyy 7->10 niin pH paperin väri lähestyy sinistä  
Kun pH lähestyy 10->14 niin pH paperin väri lähestyy purppuraa
