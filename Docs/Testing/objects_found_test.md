# Välineiden löytyminen pelitilasta

User story: Käyttäjänä pystyn löytämään tarvittavat välineet pelitilasta

Hyväksymiskriteerit:  
Dekantterilasi  
Lasisauva  
Pasteur-pipetti  
Vaaka  
pH-paperi  
Lusikka (spaatteli)  
Lusikka  
Mikrolusikka  
Tarvittavat välineet ovat huoneessa

Testitiedosto: User story on testattu manuaalisesti tarkastamalla esineiden löytyminen pelitilasta.
